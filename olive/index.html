Olive

Olive is a private, personal assistant app built and used by one person: its developer, Zhong Xuan Khwa. It runs on the developer's own home server and is not available to the public. It has no other users.

What it does

Olive connects to the developer's own Google Calendar, with the developer's consent, so that it can:

  • read upcoming events to prepare a daily schedule summary;
  • spot clashes and free time;
  • add events, and change events that Olive itself created, when the developer asks.

It asks only for two Google permissions: view and edit events on the developer's calendars (calendar.events), and list the developer's calendars (calendar.calendarlist.readonly). It does not request access to email, contacts, files or calendar sharing and settings.

Your data

Because Olive is used only by its developer, it handles only the developer's own calendar data. See the Privacy Policy for how that data is used, stored and removed.
